# BUMDes-BANYUBENING

Repository ini memuat proyek **Automated Comic Translator** di subfolder:

- [`automated-comic-translator/`](./automated-comic-translator/)
- dokumentasi utama: [`automated-comic-translator/README.md`](./automated-comic-translator/README.md)

Quick start:

### Linux / macOS

```bash
cd automated-comic-translator
./install.sh
./run.sh
```

### Windows Command Prompt

```bat
cd automated-comic-translator
install.bat
run.bat
```

### Windows PowerShell

```powershell
cd automated-comic-translator
powershell -ExecutionPolicy Bypass -File .\install.ps1
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Dokumentasi lengkap ada di `automated-comic-translator/README.md`.
